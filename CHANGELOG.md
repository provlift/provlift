# Changelog

## 0.1.0 (2026-10-31)

First public release.

### Features

* `list`, `check`, `drift`, `upgrade` and `validate` commands for Terraform and OpenTofu provider requirements across every module in a repository.
* Works with any provider in the public Terraform registry, the OpenTofu registry, or a private registry (`TF_TOKEN_*`, `.terraformrc`, `credentials.tfrc.json`).
* OpenTofu support: with `terraform.binary: tofu` (or `--terraform-binary tofu`), sources without a hostname resolve to `registry.opentofu.org`, matching OpenTofu's lock files.
* Constraint rewrites that preserve formatting and comments, honour module dependency ceilings, and gate major or breaking upgrades behind explicit acknowledgement.
* Lock files are always regenerated by Terraform/OpenTofu (`init -upgrade` → `providers lock` per platform → `validate`), never written directly.
* Provider-agnostic GitHub Actions examples that raise one reviewable pull request per provider.
